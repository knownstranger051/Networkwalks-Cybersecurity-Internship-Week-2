# 03 – DNS Enumeration

## Overview
DNS Enumeration is the process of gathering information about a domain's Domain Name System (DNS) infrastructure. It helps identify DNS records, name servers, mail servers, and other publicly available domain-related information.

## Objectives
- Identify DNS records associated with a target domain.
- Discover domain name servers.
- Understand DNS resolution.
- Gather information about the target's DNS infrastructure.
- Identify publicly exposed DNS information.

## Tools Used
- **DNSRecon:** Performs DNS enumeration and identifies available DNS records.
- **Nslookup:** Queries DNS servers to resolve domain names and retrieve DNS information.
- **WHOIS:** Provides domain registration and registrar information.

## Practical Activities
- Performed DNS enumeration using DNSRecon.
- Queried domain information using Nslookup.
- Investigated publicly available DNS records.
- Analyzed DNS enumeration results and command outputs.

## Key Learning Outcomes
- Understood DNS architecture and its role in networking.
- Learned how DNS records support domain resolution.
- Gained practical experience using DNS enumeration tools.
- Developed an understanding of how DNS information contributes to reconnaissance and attack surface assessment.
