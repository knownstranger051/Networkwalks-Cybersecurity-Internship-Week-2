# 04 – Network Scanning

## Overview
Network Scanning is the process of identifying active hosts, open ports, running services, and network configurations within a target network. It helps security professionals understand network exposure and identify potential security weaknesses.

## Objectives
- Identify active devices on a network.
- Discover open ports and running services.
- Understand network connectivity.
- Analyze scan results.
- Identify potentially exposed services.

## Tools Used
- **Nmap:** Network discovery, port scanning, and service detection.
- **Zenmap:** Graphical user interface for Nmap.
- **Kali Linux Terminal:** Executing scanning commands and analyzing results.

## Practical Activities
- Performed network discovery.
- Identified active hosts on the network.
- Conducted port scanning.
- Analyzed network scan results.
- Explored Nmap through its graphical interface using Zenmap.

## Key Learning Outcomes
- Understood the fundamentals of network scanning.
- Learned host discovery and port scanning techniques.
- Developed practical experience with Nmap and Zenmap.
- Learned how to interpret scan results and identify exposed network services.

## Environment
- Operating System: Kali Linux
- Scanning Tool: Nmap / Zenmap
- Internship: Networkwalks Cybersecurity Internship
- Project: Week 2

All scanning activities were performed for educational purposes on authorized lab systems and networks.
