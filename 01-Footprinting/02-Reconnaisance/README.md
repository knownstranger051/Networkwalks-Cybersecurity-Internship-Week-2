# 02 – Reconnaissance

## Overview
Reconnaissance is the process of collecting information about a target system, network, or organization to understand its infrastructure, technologies, and potential attack surface.

It is an important phase of ethical hacking and penetration testing.

## Objectives
- Identify publicly accessible information about the target.
- Discover domain and subdomain details.
- Identify web technologies and services.
- Analyze HTTP responses and security configurations.
- Understand the target's external attack surface.

## Tools Used
- WhatWeb – Website technology identification.
- WHOIS – Domain registration information.
- Nslookup – DNS queries and domain resolution.
- cURL – HTTP requests and response header inspection.
- Wafw00f – Web Application Firewall detection.
- DNSRecon – DNS information gathering.

## Practical Activities
- Website technology fingerprinting.
- DNS information collection.
- HTTP header inspection.
- Web Application Firewall detection.
- Domain and infrastructure reconnaissance.

## Key Learning Outcomes
- Understood the reconnaissance methodology.
- Learned to use command-line tools for information gathering.
- Gained practical experience analyzing website technologies and HTTP responses.
- Developed an understanding of how reconnaissance helps identify an external attack surface.
